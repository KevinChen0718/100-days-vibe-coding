> Day 5 of 100 Days Vibe Coding。致敬 1998 年 Pyro Studios《Commandos: Behind Enemy Lines》第一關，
> 即時戰術潛行遊戲（Real-Time Tactics / Stealth）。

---

## 1. 版權研究結論（為什麼可以做、怎麼做才安全）

### Chrono Divide（網頁版紅色警戒 2）為什麼沒事？

它守住了兩條法律界線：

1. **程式碼 clean-room 重寫**：引擎用 TypeScript 從零寫，沒看過、沒用過 Westwood 原始碼。
   遊戲「機制與規則」不受著作權保護（只有具體的表達——程式碼、美術、音效——受保護）。
2. **一個原版素材都不附**：網站上那個「Locate original game assets」匯入畫面就是整個法律防線——
   圖像、音效、地圖全部要玩家自備正版 RA2 檔案，作者只發行自己寫的引擎。
   同模式的先例：OpenRA、OpenTTD、CorsixTH，都活得好好的。

### Commandos 的情況比 EA 更要小心

- 「Commandos」商標目前在 **Kalypso Media Group GmbH** 手上（2018 年購入）。
- 這個 IP 是**活的**：2025 年 4 月才剛出新作《Commandos: Origins》（Steam / Game Pass）。
  活躍商業 IP 的權利方比 EA 那種「老 IP 放著」更有動機維權。

### 本專案採用的路線（沿用 Day 4 已踩穩的界線）

| 項目 | 做法 |
|:--|:--|
| 遊戲機制（視野錐、潛行、即時戰術） | 照做——機制不受著作權保護 |
| 名稱 | 原創《霜峽行動 Operation Frostfjord》，不用 Commandos 字樣當作品名 |
| 角色 | 原創代號（狼／海豹／狐），不用 Jack O'Hara 等原作角色 |
| 美術音效 | 全部 Canvas 向量手繪 + WebAudio 合成，零外部素材 |
| 關卡 | 致敬原作第一關的「任務結構」，地圖重新設計，不複製原作地圖 |
| README 提及原作 | 可以（指名性使用），「inspired by Commandos」合法 |

連 Chrono Divide 那招「素材匯入」都不需要——我們根本不用任何原版檔案。

## 2. 原作第一關考據（Baptism of Fire, 1941 年挪威）

研究來源：Commandos Wiki、IGN 攻略、GameFAQs。

- 背景：德軍佔領下的挪威，Stavanger 機場旁的 Sola 無線電中繼站。
- 隊伍：**綠扁帽（Green Beret）、工兵駕駛（Driver）、蛙人（Marine）**，三人分散登陸。
- 流程：三人會合 → 奪取一艘小艇 → 蛙人開船渡海到北邊小島 → 用島上的**油桶**炸掉中繼站 → 撤離。
- 招牌機制：敵兵**視野錐**（近區必被發現、遠區蹲低潛行不會）、背後刀殺、搬運屍體、
  快速存檔讀檔（quicksave 是 Commandos 玩法精髓）、雪地腳印會被士兵跟蹤。

## 3. 遊戲規格

### 核心玩法

- **即時戰術潛行**，上帝視角 2D，滑鼠點擊移動（A* 尋路），任何一名隊員死亡 = 任務失敗。
- **三角色切換**（按 1/2/3 或點頭像），各有專屬能力：

| 代號 | 致敬原型 | 專屬能力 |
|:--|:--|:--|
| 狼 Wolf | 綠扁帽 | 背後刀殺、搬運屍體／油桶、丟誘餌發聲器 |
| 海豹 Seal | 蛙人 | 唯一會開船的人 |
| 狐 Fox | 駕駛 | 手槍（6 發，響聲會引來敵兵） |

### 敵兵 AI（本作的靈魂）

- **視野錐雙區**（原作招牌）：
  - 近區（4 格）：進入就被發現，蹲也沒用
  - 遠區（4–8 格）:站立／搬東西會被發現，**蹲低緩行不會**
  - 視線被樹、岩石、建築擋住
- **三態 FSM**：`巡邏 PATROL` →（目擊值累積／聽到聲音）→ `起疑 SUSPICIOUS ?`（走過去查看）→
  （目擊值滿）→ `警戒 ALERT !`（追擊、瞄準 0.7 秒後開槍、呼叫附近隊友）。
- 發現**屍體** → 立即警戒並搜索周邊。
- 聽覺：槍聲／爆炸大範圍示警，誘餌發聲器吸引敵兵離開崗位。

### 第一關任務鏈（致敬重設計）

```
三人分散登陸南岸 → 會合 → 摸掉碼頭哨兵奪小艇 → 海豹開船渡海峽 →
小島滲透 → 狼搬油桶到中繼站 → 點燃 8 秒引信 → 轟 → 全員回船 → 駛回南岸碼頭 = 過關
```

### 操作

| 鍵 | 功能 |
|:--|:--|
| 左鍵點地 | 移動（點敵人＝狼刀殺指令／狐射擊） |
| 1 / 2 / 3 | 切換角色 |
| C / 右鍵 | 蹲低（潛行） |
| E | 撿起／放下（屍體、油桶） |
| F | 互動（上下船、放置油桶、點引信） |
| Q | 丟誘餌發聲器 |
| V | 切換視野錐顯示 |
| K / L | 快速存檔／讀檔（致敬原作 Ctrl+S） |
| R | 重新開始 |

## 4. 技術架構

沿用馬拉松慣例：**純前端、零依賴、零建置**，`file://` 直接打開 `index.html` 就能玩。
沿用 Day 1 / Day 4 驗證過的架構：**引擎純邏輯零 DOM（Node 可測）+ 渲染分離**。

```
day-005-frostfjord/
├── index.html        # 入口，plain <script> 載入（不用 ES module，保住 file:// 可開）
├── style.css
├── js/
│   ├── data.js       # 常數 + 第一關資料（ASCII 地圖、敵兵配置、簡報文字）→ 之後加關卡只動這檔
│   ├── engine.js     # 純邏輯：A* 尋路、視野錐偵測、AI FSM、動作系統、存讀檔（零 DOM）
│   ├── render.js     # Canvas 向量手繪：雪地地形、角色、視野錐、UI
│   ├── audio.js      # WebAudio 合成音效（刀、槍、爆炸、引信、環境風聲）
│   └── main.js       # 輸入處理 + 遊戲迴圈 + 鏡頭跟隨
└── test/
    └── sim.js        # Node 回歸測試：LoS、視野錐規則、FSM 轉換、刀殺判定、腳本化通關驗證
```

地圖用 **ASCII 字元畫**（50×34 格，一格 32px）：`~`水 `.`雪 `r`路 `T`樹 `R`岩 `#`牆 `D`棧橋 `b`灌木…
好讀好改，第二關之後純加資料。

## 5. 開發分工（逐一開發的里程碑）

| 里程碑 | 內容 | 驗收標準 |
|:--|:--|:--|
| M1 地基 | 地圖載入、A* 尋路、點擊移動、鏡頭跟隨 | 三角色能在地圖上跑、不穿牆 |
| M2 敵兵 | 視野錐雙區 + LoS + 三態 FSM + 巡邏 | 站著走進遠區被抓、蹲低能溜過、近區必死 |
| M3 狼的能力 | 背後刀殺、搬屍體、誘餌 | 正面刀不到、屍體被看到會警戒 |
| M4 三人協作 | 角色切換、海豹開船、狐手槍 | 沒海豹船不能開、槍聲引來敵兵 |
| M5 任務鏈 | 油桶、引信爆炸、撤離判定、簡報／勝敗畫面 | 腳本化輸入可從頭打到通關 |
| M6 打磨 | 音效、雪地腳印（視覺）、存讀檔、提示列 | 手感與氛圍 |

每個里程碑完成就跑一次 `node test/sim.js` 回歸（Day 4 教訓：AI 參數要量化統計，不要用猜的）。

### 測試策略

- `test/sim.js` 用 Node 直接驅動 engine.js（零 DOM 的好處）：
  - 單元：raycast 被牆擋、雙區偵測規則矩陣（站/蹲 × 近/遠）、刀殺角度判定
  - 整合:**腳本化通關**——一串預錄指令餵進引擎，斷言最後狀態是 WIN（保證關卡永遠可解）
- 瀏覽器端用 Playwright 截圖目視驗收。

## 6. 美術方向

- 挪威冬夜：深藍夜空 + 雪地藍白 + 暖黃窗光點綴，全 Canvas 向量。
- 視野錐：常態半透明黃、起疑橘、警戒紅——一眼讀懂威脅。
- 角色小巧但輪廓分明（深色突擊服 vs 德軍灰藍大衣），頭頂狀態圖示（? / !）。
