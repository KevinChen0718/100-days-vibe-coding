# Day 4 原創角色 Sprite 重畫設計

日期：2026-07-22  
狀態：Kevin 已確認；五位角色已實作並通過自動測試與瀏覽器 QA

## 背景

Day 4 的選單、HUD、狀態畫面已完成 Graphic Arcade 重畫，但戰鬥人物仍由低解析度 Canvas 骨架、線段與幾何形狀組成。人物在實際遊戲尺寸下缺少臉部、服裝、手掌、鞋子與身形差異，因此即使 UI 已升級，戰鬥畫面仍有明顯的火柴人感。

本次工作要把角色層從程序式骨架換成真正的透明 Sprite Atlas，並將現有 5 位致敬角色改造成自有角色。戰鬥規則與平衡不變。

## 目標

- 5 位角色全部改成約 3 頭身的原創 Q 版格鬥人物。
- 遊戲內角色高度約 90～105px，能辨識五官、髮型、服裝、拳腳與角色職業。
- 每位角色具備 12 個核心姿勢，覆蓋主要戰鬥狀態。
- 選角、戰鬥、勝負等畫面使用同一套角色資產。
- 維持既有碰撞、AI、招式數值、操作與關卡節奏。

## 非目標

- 不修改場景、HUD 或其他兩款遊戲。
- 不新增角色、招式、武器或戰鬥模式。
- 不重做技能特效、音效或輸入系統。
- 不改碰撞箱、傷害、MP、速度、AI 或勝負判定。
- 不使用 LF2 原作角色圖、Sprite 或人物設定。

## 美術方向

- 比例：2.5～3 頭身，頭部與拳腳略放大，肩線與服裝外輪廓清楚。
- 畫風：90 年代街機格鬥人物經現代動畫海報重製，與 Graphic Arcade HUD 相容。
- 線條：粗黑外輪廓，內部以較細深色線表現衣摺、護具與五官。
- 光影：每個人物使用一個主要明面、一個陰影面與少量高光，避免縮小後變髒。
- 色彩：每人保留唯一主色與辨識物；隊伍紅藍色僅作 HUD／受擊提示，不覆蓋角色自身配色。
- 可讀性：人物縮到 90px 高時，髮型、上衣、手部、鞋子與角色武器仍須分得開。
- 原創性：不複製 LF2 原作人物的臉、衣服剪裁、姿勢或 Sprite 排列。

## Sprite Atlas 規格

每位角色一張透明 Atlas，固定 `4 × 3` 網格，共 12 格。所有 Atlas 使用相同畫布尺寸、格子順序、腳底定位點與留白。

| 格位 | 姿勢 | 使用狀態 |
|---|---|---|
| 1 | 待機 A | `idle` 第一拍 |
| 2 | 待機 B | `idle` 第二拍、呼吸循環 |
| 3 | 走路 A | `walk` 第一拍 |
| 4 | 走路 B | `walk` 第二拍 |
| 5 | 奔跑 | `run`、`runattack` 起手 |
| 6 | 跳躍 | `jump`、`flip` 基底 |
| 7 | 出拳 | 普通拳、武器揮擊、抓人起手 |
| 8 | 踢擊 | 普通踢、連環踢、跳踢、翻身踢 |
| 9 | 防禦 | `defend`、接招前姿勢 |
| 10 | 必殺技／施法 | 氣功、火焰、冰凍、瞬身等特殊狀態 |
| 11 | 受傷／倒地 | `hurt`、`fall`、`lying`、`caught`，由渲染層附加旋轉與位移 |
| 12 | 勝利 | `win`、選角畫面英雄姿勢 |

### 圖像格式

- 來源資產先以平坦色背景生成，再移除背景並檢查透明邊緣。
- 專案最終使用支援 alpha 的 PNG 或 lossless WebP；若 WebP 在細線與透明邊緣出現色暈，保留 PNG。
- 每格保持一致的腳底中央錨點，角色不可超出格子或與相鄰格互相重疊。
- 角色面向以單一方向繪製；遊戲依 `facing` 水平翻轉。
- 正常戰鬥顯示高度約 90～105px；選角與結果畫面可放大，但不得重新裁切造成頭腳缺失。

## 執行時架構

1. 新增角色 Atlas 載入器，集中管理五張圖片與載入狀態。
2. 新增「引擎狀態 → Atlas 格位」的純函式，避免把判斷散落在各畫面。
3. `drawFighter` 改為：
   - 取得目前姿勢格位。
   - 以腳底中央對齊世界座標 `f.x`、`f.z - f.y`。
   - 依 `facing` 水平翻轉。
   - 套用既有閃白、無敵閃爍、冰凍、旋轉、跳躍高度與特殊光效。
4. 選角、標題與結果畫面使用同一個 Atlas 繪製 helper，避免另一套人物畫法。
5. Atlas 尚未完成載入或載入失敗時，單一角色暫時回退至舊的 Canvas 人物；其他已載入角色不受影響。
6. 既有程序式人物渲染先保留為 fallback，待五張 Atlas 均通過實機驗收後再決定是否移除；本次不做額外清理重構。

## 資料與相容性

- `CHARS` 改為新 ID 與新顯示名稱，數值與 `moves` 內容維持原值。
- 測試若以舊 ID 建立角色，使用單一 `LEGACY_CHAR_IDS` 映射到新 ID。
- Replay／快速設定若不存在持久化角色 ID，無需額外遷移；若檢查後存在，讀取舊值時映射、寫入時只寫新 ID。
- Sprite 僅影響顯示，不進入引擎命中計算。

## 錯誤處理

- 單一 Atlas 404、解碼失敗或尺寸不符時，在 console 回報角色 ID 與檔案路徑，並使用舊人物 fallback。
- Atlas 格位索引超出範圍時回退至待機 A，不中斷遊戲迴圈。
- 開發模式檢查五張 Atlas 尺寸與 `4 × 3` 格位可整除；正式畫面不顯示除錯框。
- 圖片載入不阻塞標題畫面與輸入。
